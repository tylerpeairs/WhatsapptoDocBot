Session Security:

Ensure your Flask application is configured to use a secure, randomly generated session secret key. Flask sessions are signed, but not encrypted, so sensitive information should not be stored directly in session variables. If you're storing the entire credentials object in the session, consider the security implications and possibly storing only non-sensitive parts or references.
HTTPS Enforcement:

Your OAuth callback URI should be using HTTPS to ensure that all communications between the client, your server, and Google's servers are encrypted. This is especially important for OAuth flows to prevent MITM attacks.

Recommendations

Code Reviews and Testing: Conduct security reviews and testing specifically focused on authentication flows, session management, and data handling.
